      Welcome to the Sphere Radio LibreTime Tagger

      What it is

      A small tool that prepares MP3 files for the Sphere Radio LibreTime library. You fill in a short form and it writes the tags, the cover image and the filename for you.

      How it works

      1. Choose or drop an MP3 file.
      2. Pick your show, then add the episode, contributors, and broadcast date.
      3. Add a cover image and choose the square cut.
      4. Check the summary and save.

      If you are usually tagging the same show, you can associate it with a primary cover and primary contributor. This will automatically load both once you select the show from the list.

      Why it exists

      When every file is named and tagged differently, the LibreTime library gets messy. This tagger asks only for what LibreTime needs and removes everything else, so every file looks the same.

      Everything runs in your browser. Your audio files are never uploaded. Your show lists and primary contributors and covers are only saved in your browser's local storage.

      About this tagger

      This tagger is for Sphere Radio contributors. Its goal is to simplify tagging MP3 files according to the Sphere Radio tagging scheme for LibreTime.

      Sphere Radio e.V. is an interdisciplinary community radio based in Leipzig, Germany. For more info visit sphere-radio.net.
